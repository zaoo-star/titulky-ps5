# PlayStation 5 – preparation (first time only)

ReCaption marks the two accounts the same way everywhere:

- 🔵 **Account for ReCaption** – a second account, only for ReCaption (sign-in on Sony's page, Remote Play, the eight-digit number)
- 🟢 **Gaming account** – the one you play on (games, trophies and friends stay on it)

**Why two accounts:** ReCaption takes a copy of the picture from the PS5 via Remote Play. If it connected with the 🟢 gaming account,
the PS5 would treat it as "the game has moved somewhere else" – it would switch off your controller and blank the picture. The 🔵 account only "watches".
Exception: ReCaption for PC in **Play on PC** mode (see the overview below).

<a id="kde"></a>
## Who signs in where (overview)

E-mail and password are typed **only ever on Sony's page** – on a phone or in a computer's browser. The password is
never typed into the TV or into ReCaption. ReCaption only remembers the account's number and name.

| ReCaption runs on | Account | Where e-mail and password are typed |
|---|---|---|
| **Android TV / box** with a remote | 🔵 | on a phone (Android or iPhone) or in a computer's browser: scan the square from the TV → ReCaption page → Sony sign-in; nothing is typed with the TV remote |
| **Android phone** (helper, or reader for an LG / Samsung TV) | 🔵 | right inside ReCaption on the phone, on Sony's page; the helper always starts clean, e-mail and password are typed every time |
| **iPhone** (only the page from the TV, there is no iPhone app) | 🔵 | in Safari on Sony's page, then copy the address of the blank "redirect" page and paste it into the ReCaption page |
| **PC – TV reader** (the game goes from the PS5 to the TV) | 🔵 | on a phone via the square from the PC window, or in the PC's browser |
| **PC – Play on PC** (the game runs in the chiaki-ng window) | 🟢 | on a phone via the square from the PC window, or in the PC's browser; no second account needed here |
| **PS5** (once, when adding the 🔵 user – step 2) | 🔵 | directly on the PS5 with the controller, or with a phone via the square the PS5 offers itself |

<a id="prohlizec"></a>
**Watch out for signing in "by itself":** if the 🟢 gaming account is already signed in in the phone's or PC's browser
(for example from PlayStation Store), Sony won't ask for a password and takes that one – ReCaption then shows "Verified account: 🔵 NAME"
with the gaming account's name. In that case choose **Sign in another account** and open the ReCaption page in a private/incognito window
(Safari: private tab), or sign out on Sony's page first. ReCaption on an Android phone takes care of this by itself.

<a id="ucet"></a>
## 1. 🔵 Create the account for ReCaption (free)

👉 **[Create a PlayStation account](https://www.playstation.com/cs-cz/support/account/create-account-for-psn/)**
(on a phone or computer), or directly on the PS5 in step 2 (**Create an Account**).

- Use a **different e-mail** from the 🟢 gaming account and confirm it in the e-mail you receive.
- Enter an adult's date of birth – Remote Play is restricted on a child account. The date and country can't be changed later.
- The 🔵 account doesn't need PlayStation Plus or any games.

If the link doesn't work:
- [Sony's guide (English)](https://www.playstation.com/en-gb/support/account/create-account-for-psn/)
- or search for: **"create PlayStation Network account"**

<a id="uzivatel"></a>
## 2. 🔵 Add it to the PS5 as another user

Creating the account on the web isn't enough – the PS5 needs a 🔵 user you can switch to.

1. On the PS5 home screen choose the **profile icon** at the top right → **Switch User**
   (or PS button → profile icon → Switch User).
2. On the "Who's using this controller?" screen choose **Add User** → **Add User to This PS5**
   → **Get Started** – not "Play as a Guest" (a guest can't be paired). Accept the user agreement (**Agree** → **Confirm**).
3. **Sign In with QR Code** – scan the square with a phone, or **Sign In Manually** (e-mail and password with the controller).
   If you don't have the account yet, choose **Create an Account** (Your info – country and language, then sign-in ID and password).
4. Remember the new user's name (Online ID) – ReCaption then shows it as "🔵 NAME".


<a id="remote-play"></a>
## 3. Remote Play on the PS5

On the PS5 switch to the **🔵 user** and in **Settings → System → Remote Play** turn on:

- **Enable Remote Play** – opens a list of users with switches; turn on the switch for the **🔵 user**,
- **Hide Remote Play Connection Status Pop-Up** – otherwise the message "Remote Play app is connected"
  shows during the game. Turn this on under the 🟢 gaming user too. If the option isn't there,
  update the PS5 system software.

Don't use **Pair Device** (in older system software **Link Device**, same place) yet – that comes in the last pairing step (step 5).

[Sony's Remote Play guide](https://www.playstation.com/cs-cz/support/games/remote-play-settings/)

<a id="probouzeni"></a>
## 4. Waking from rest mode (optional)

Only for the option ⚙ Settings → General → **Wake the PlayStation** (off by default). On the PS5 (under any user):
**Settings → System → Power Saving → Features Available in Rest Mode** → turn on
**Stay Connected to the Internet** and **Enable Turning On PS5 from Network**.
A PS5 woken this way starts on the 🔵 user – then switch to the 🟢 gaming account with the controller.

<a id="parovani"></a>
## 5. Pairing (in this order)

In ReCaption: the "Connecting the PlayStation" step (guide), or the **Console** page. Six steps, each showing where it's done:

| Step in ReCaption | Where | What to do |
|---|---|---|
| 1 · Turn on the PlayStation | 🎮 PS5 | turn it on, same home network as the device running ReCaption |
| 2 · Find the PlayStation | 📺 ReCaption | found automatically; otherwise the address from the PS5: Settings → Network → View Connection Status → IPv4 Address |
| 3 · 🔵 Account for ReCaption | 📺 ReCaption | **Use account 🔵 NAME** (already verified), or **Sign in with the account** |
| 4 · Sign-in | 📱 phone / 💻 browser | e-mail and password of the **🔵** account on Sony's page (see the [overview](#kde)); ReCaption then shows **"Verified account: 🔵 NAME"** |
| 5 · Remote Play on the PS5 | 🎮 PS5 | switch to the user **🔵 NAME**, check step 3 |
| 6 · Number from the PS5 | 🎮 PS5 → 📺 ReCaption | under **🔵 NAME**: Settings → System → Remote Play → **Pair Device** (older system: Link Device); type the eight-digit number into ReCaption (a phone can also read it with the camera) – it's valid for a few minutes |

Done: "Paired (account 🔵 NAME)". **Then switch the PS5 back to the 🟢 gaming account** and play. Pairing is only needed once.

<a id="ce-110032-7"></a>
**Error CE‑110032‑7 / "Regist failed":** the number was brought up on the PS5 by a **different user** than the one ReCaption
signed in with. On the PS5 switch to the user whose name ReCaption shows and bring up a new number – or in ReCaption
choose **Sign in another account**. If ReCaption shows the name of the 🟢 gaming account, it signed in wrongly (see
[Watch out for signing in "by itself"](#prohlizec)). After pairing, switch back to the 🟢 gaming account on the controller.
